# Trabajo Práctico 1

Trabajo práctico correspondiente a la asignatura **Comunicaciones de Datos**.

## Estructura

```text
TP1/
├── assets/
├── informe.md
├── notebook/
└── pkt/
```

### `informe.md`

Documento principal del trabajo práctico. Contiene el desarrollo de las consignas, análisis, resultados y referencias.

### `assets/`

Recursos gráficos utilizados en el informe, incluyendo imágenes provistas por la consigna y gráficos generados durante el desarrollo del trabajo.

### `notebook/`

Material utilizado para realizar análisis y simulaciones mediante Python y Jupyter Notebook.

* `tp1_punto3.ipynb`: análisis y representación de señales digitales y modulación BPSK.
* `tp1_utils.py`: funciones auxiliares utilizadas por la notebook.

La notebook se utiliza como recurso de análisis y generación de gráficos; los resultados relevantes para las consignas se incorporan al informe.

### `pkt/`

Archivos de Cisco Packet Tracer utilizados para las actividades que requieren simulación de redes.

* `Tp1.pkt`: topología y configuración.
